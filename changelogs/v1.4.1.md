# v1.4.1

## Improvements

- **TypeScript v6 Upgrade** — Upgraded TypeScript to v6 (`^6.0.3`) with full support across compiler checks, ESLint, and test runners.
- **Dependency Optimization & Pruning** — Streamlined `devDependencies` by removing unused dependencies (`canvas`, `ts-node`, and redundant `@types/eslint`), eliminating native C++ build overhead (`node-gyp rebuild`) and trimming 47+ transitive dependencies.
- **Modern ESLint Configuration** — Migrated `eslint.config.ts` to standard Node ESM `eslint.config.mjs`, eliminating the `jiti` runtime loader requirement while maintaining full type safety and existing lint rules.
- **Upgraded DevDependencies to Latest** — Updated all developer tooling to their latest stable releases (`@types/chrome`, `@types/node`, `@typescript-eslint/*`, `eslint`, `fast-check`, `jest`, `prettier`, and `tsx`), achieving zero audit vulnerabilities.
