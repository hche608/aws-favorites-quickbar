# v1.4.0

## Fixes

- **Accurate Developer Tools & Service ID Resolution** — Fixed a bug where services sharing the `/codesuite/` umbrella path (such as CodeBuild, CodePipeline, CodeCommit, and CodeDeploy) collided under a shared `"codesuite"` ID in storage, quickbar injection, and pinning. Service IDs are now directly and accurately parsed from `/<serviceId>/home` URLs.
- **Icon Extraction Alignment** — Updated the background icon extractor to identify services via `/<serviceId>/home`, preventing icon collisions between nested services.

## Improvements

- **Eliminated Fallback Patterns** — Removed cascading fallback heuristics from URL parsing and the popup service click handler, enforcing strict explicit conditionals and single responsibility.
- **Streamlined Popup State Updates** — Cleaned up `service-click-handler.ts` by requiring `onFavoritesChanged` callback and eliminating dead DOM-mutation fallback code.
- **Development Tooling** — Added `mise.toml` configuring Node.js 24.
- **Dependency Updates** — Upgraded `@types/chrome`, `@types/node`, `@typescript-eslint/*`, `esbuild`, `eslint`, and `tsx` to their latest stable versions.
