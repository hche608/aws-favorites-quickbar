# v1.5.0

## New Features

- **AWS CodePipeline Execution Hover Preview** — Hovering over any pipeline link in the AWS Console (in tables, breadcrumbs, search results, or quickbar links) displays a rich, native-styled floating popover showing the latest execution ID, status (Succeeded, InProgress, Failed, Stopped), duration, start time, stage breakdown, and action details without needing to open the pipeline page.
- **Dynamic Light Beam Animation for In-Progress Stages** — Stages currently in progress feature an elegant flowing light beam animation along their borders, while maintaining a clean, distraction-free popover aesthetic. Supports `prefers-reduced-motion` for accessibility.
- **Main-World Console Session Bridge with SigV4 Signing** — Zero-credential, zero-backend architecture. Injects a lightweight `main-world.ts` script to sign `CodePipeline_20150709.GetPipelineState` requests using the browser's active AWS Console session credentials via Web Crypto API.
- **Configurable Hover Delay & Toggle in Settings** — Added popup settings controls:
  - Toggle switch for CodePipeline Execution Hover Preview (`codePipelineHoverEnabled`, default: `true`).
  - Configurable delay selector (`codePipelineHoverDelay`, default: `1.5s`, options: `0.5s` to `3.0s`).
  - Interactive auto-disabling of delay selector when the feature is turned off.

## Enhancements & UI Modernization

- **Two-Row Settings Toolbar** — Modernized the extension popup settings area into a clean, 2-row layout (Row 1: Max Services limit & VisualMode theme; Row 2: CodePipeline toggle & Hover Delay selector). Resolves horizontal layout cramping, prevents offscreen overflow, and eliminates the white scrollbar gutter in the Chrome popup container.
- **Stale-While-Revalidate TTL Caching** — Popover data caches pipeline execution state for 15 seconds (5 seconds for `InProgress`), with background revalidation and automatic fallback to cached data if network requests fail.
- **Accessibility & Dismissal Handlers** — Pressing `Escape`, scrolling the window, or clicking outside immediately dismisses the floating popover. All dismiss listeners verify `target instanceof Node` for SVG compatibility.
- **Strict XSS Defense** — All pipeline names, stage names, action names, error causes, and durations are escaped via `escapeHtml()` before rendering into the DOM.

## Testing & Developer Experience

- **Offline Code-Based UI Layout Invariant Tests** — Added `npm run test:ui:offline` executing pure code-based Playwright invariant specs (`tests/e2e/popup-layout-invariants.spec.ts` and `tests/e2e/codepipeline-hover-invariants.spec.ts`). Validates popover boundary containment, zero horizontal popup overflow, 2-row layout geometry, and interactive state changes in <8 seconds with zero external network or AWS credential dependencies.
- **Test Suite Expansion** — Expanded test coverage to 41 test files with 516 unit & integration tests passing (100%) and 16 Playwright E2E spec files (38 tests).
- **Dependabot Tooling Protection** — Added ignore rule for `typescript` major updates (`version-update:semver-major`) in `.github/dependabot.yml` to maintain strict compatibility with `@typescript-eslint` ecosystem.
