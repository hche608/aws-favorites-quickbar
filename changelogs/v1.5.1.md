# v1.5.1

## Bug Fixes

- **VPC Console Route & Icon Resolution (`/vpcconsole/home`)** — Fixed an issue where visiting the AWS VPC Console (`https://<region>.console.aws.amazon.com/vpcconsole/home`) failed to extract the proper display name and official icon, incorrectly displaying "Vpcconsole" with a fallback box. The service ID is now properly normalized to `vpc`, rendering the official branded display name **"VPC"** and loading the official AWS CloudFront CDN SVG icon.

## Enhancements & Architecture

- **Canonical Service ID & Path Alias Normalization Engine (`src/services/service-aliases.ts`)** — Introduced a centralized mapping table `SERVICE_ID_ALIASES` and helper `normalizeServiceId()` to seamlessly bridge AWS micro-frontend routing tokens and brand aliases with canonical catalog IDs:
  - Modern micro-frontends: `vpcconsole` -> `vpc`, `iamv2` -> `iam`, `wafv2`/`waf` -> `wafv2-pro`, `appstream` -> `appstream2`.
  - Brand name vs internal console namespaces: `stepfunctions` -> `states`, `opensearch`/`es` -> `aos`, `identitycenter` -> `singlesignon`, `billing`/`cost-management` -> `costmanagement`, `certificate-manager` -> `acm`, `beanstalk` -> `elasticbeanstalk`, `ssm` -> `systems-manager`, `eventbridge` -> `events`, `quicksight` -> `qs`, `documentdb` -> `docdb`.
- **Cross-Layer Deduplication & Catalog Alignment** — Updated `service-merger.ts`, `content.ts`, `content-updater.ts`, and `service-icons.ts` to normalize service IDs during comparison, preventing duplicate pinned/recent entries when navigating between different console entrypoints for the same service.
- **Service Catalog Brand Display Names** — Added verified brand names in `KNOWN_SERVICE_NAMES` for all aliased services (e.g. `Step Functions`, `OpenSearch`, `IAM Identity Center`, `WAF & Shield`, `Systems Manager`, `EventBridge`, `QuickSight`, `DocumentDB`).

## Testing & Quality Assurance

- **Real Browser In-Engine E2E Validation (`tests/e2e/real-browser-services.spec.ts`)** — Added dedicated Playwright Chromium tests validating:
  - Official CloudFront CDN SVG icon network loading and real browser decoding (`naturalWidth > 0 && naturalHeight > 0`).
  - Active recent service detection, URL construction, and Quickbar mounting when visiting `/vpcconsole/home`, `/iamv2/home`, and `/stepfunctions/home`.
  - Visual verification screenshot artifacts saved in `test-results/`.
- **Unit Test Coverage** — Added comprehensive unit tests in `tests/unit/services/service-aliases.test.ts` and `tests/unit/services/vpc-console.test.ts`, covering all 17 canonical alias pairs, URL parsing, deduplication invariants, and icon resolution. Vitest test suite expanded to 43 files with 518 passing tests (100%).
- **Strict Architecture Invariant Enforcement** — All new and modified files remain strictly under 300 lines of code (Rule 2) with zero fallback heuristics (Rule 1).
